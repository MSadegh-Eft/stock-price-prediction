# Stock Price Prediction App

A compact Streamlit application for exploring historical stock prices, engineering market features, and comparing forecasting models.

## Features

- Download stock data with `yfinance`
- Compute technical features such as high-low percentage and daily percent change
- Train and evaluate Linear Regression and Support Vector Regression models
- Display model predictions and future price forecasts

## Setup

```bash
python -m pip install -r requirements.txt
streamlit run App.py
```

## Requirements

- Python 3.10+
- Streamlit
- yfinance
- numpy
- matplotlib
- scikit-learn
